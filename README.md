## 🚀 Быстрая установка

Одна команда для полной установки бота:

```bash
curl -fsSL https://raw.githubusercontent.com/RamaPulya/bot_auto_install/spiderman/scripts/quick-install.sh | sudo bash
```

## 🌐 Настройка DNS записей

> ⚠️ **Важно:** Настройте DNS записи **ДО** запуска установки!

### Необходимые записи

Создайте **A-записи** у вашего регистратора домена, указывающие на IP вашего сервера:

| Запись | Тип | Значение | Назначение |
|--------|-----|----------|------------|
| `hooks.yourdomain.com` | A | `IP сервера` | Webhook для бота и платёжных систем |
| `mini.yourdomain.com` | A | `IP сервера` | Mini App (веб-интерфейс) |

### Пример настройки

```
Домен: yourdomain.com
IP сервера: 123.45.67.89

DNS записи:
hooks.yourdomain.com  →  A  →  123.45.67.89
mini.yourdomain.com   →  A  →  123.45.67.89
```

### Проверка DNS

После создания записей подождите 5-15 минут и проверьте:

```bash
# Проверить webhook домен
dig +short hooks.yourdomain.com

# Проверить miniapp домен
dig +short mini.yourdomain.com
```

> 💡 Установщик автоматически проверит DNS записи. Если запись не найдена — вы сможете пропустить и настроить позже.

## 🔧 Процесс установки

### Шаг 1: Запустите установщик

```bash
curl -fsSL https://raw.githubusercontent.com/RamaPulya/bot_auto_install/spiderman/scripts/quick-install.sh | sudo bash
```

### Шаг 2: Следуйте мастеру установки

Скрипт проведёт вас через все этапы:

```
1️⃣  Выбор директории установки (/opt или /root)
2️⃣  Проверка панели Remnawave (автоматически)
3️⃣  Ввод BOT_TOKEN
4️⃣  Ввод ADMIN_IDS
5️⃣  Настройка REMNAWAVE_API_URL (автоматически для локальной панели)
6️⃣  Ввод REMNAWAVE_API_KEY
7️⃣  Настройка доменов (webhook и miniapp)
8️⃣  Получение SSL сертификатов
9️⃣  Запуск Docker контейнеров
🔟  Готово!
```

### Шаг 3: Проверьте работу

После установки используйте команду `bot` для управления.

## 🔄 Обновление существующей установки

Если у вас уже установлен бот старой версией скрипта и нет команды `bot`:


Скрипт предложит:
```
Что вы хотите сделать?

  1) 📦 Обновить бота (git pull + rebuild)
  2) 🎮 Установить команду 'bot' (если нет)
  3) 🔧 Обновить скрипты установщика
  4) 📋 Всё вместе (рекомендуется)
  0) Отмена
```

После обновления команда `bot` станет доступна из любого места.

## 🏗️ Варианты установки

### Вариант 1: Бот + Панель на одном сервере (рекомендуется)

Если панель Remnawave уже установлена на этом сервере:

- ✅ Скрипт автоматически обнаружит панель
- ✅ Подключит бота к Docker сети панели
- ✅ Использует внутренний адрес `http://remnawave:3000`
- ✅ Добавит конфигурацию в nginx панели

### Вариант 2: Бот на отдельном сервере

Если панель на другом сервере:

- Укажите внешний URL панели (https://panel.yourdomain.com)
- Бот создаст собственную Docker сеть
- Необходим системный nginx для SSL

## 🛡️ Безопасность

Скрипт автоматически настраивает:

- ✅ **UFW Firewall** — открыты только порты 22, 80, 443
- ✅ **SSL/TLS** — автоматические сертификаты Let's Encrypt
- ✅ **Защита .env** — файл доступен только root (chmod 600)
- ✅ **Случайные токены** — автогенерация секретных ключей

### 🔐 Дополнительная защита сервера

> 💡 **Рекомендуем** дополнительно защитить ваш сервер — ограничить SSH доступ только для вашего IP и установить Fail2Ban для защиты от брутфорса.
>
> Используйте наш проект **[Server Shield](https://github.com/wrx861/server-shield)** для автоматической настройки защиты.

## 🆘 Устранение проблем

<details>
<summary><b>🔴 Бот не запускается</b></summary>

```bash
# Посмотреть логи
docker compose logs -f bot

# Проверить статус контейнеров
docker compose ps

# Перезапустить
docker compose restart bot
```
</details>

<details>
<summary><b>🔴 Ошибка базы данных</b></summary>

```bash
# Проверить PostgreSQL
docker compose exec postgres pg_isready

# Логи базы данных
docker compose logs postgres
```
</details>

<details>
<summary><b>🔴 SSL сертификат не работает</b></summary>

```bash
# Проверить конфигурацию nginx
nginx -t

# Перезапустить nginx
systemctl restart nginx

# Получить сертификат вручную
certbot --nginx -d yourdomain.com
```
</details>

<details>
<summary><b>🔴 Mini App показывает ошибку</b></summary>

```bash
# Проверить что nginx видит файлы miniapp
ls -la /opt/remnawave-bedolaga-telegram-bot/miniapp/

# Перезапустить nginx панели (если используется)
cd /opt/remnawave && docker compose restart remnawave-nginx

# Или системный nginx
systemctl restart nginx
```
</details>
